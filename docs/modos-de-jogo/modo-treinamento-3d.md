# Coup Master 3D - Modo Treinamento

O **Modo Treinamento 3D** e um modo planejado para ensinar controles, testar interacoes e permitir pratica individual.

## Objetivo

Reduzir a barreira de entrada do Coup Master 3D, principalmente para jogadores novos em mesa 3D, touch/mobile ou atalhos de teclado.

## Entrada Planejada

- Pode funcionar com visitante.
- Deve poder abrir sem sala multiplayer.
- Pode usar estado local ou uma sala temporaria isolada.

## Conteudos Planejados

- Tutorial de camera.
- Comprar carta do baralho.
- Arrastar carta para a mesa.
- Virar carta.
- Criar e mover pilha.
- Devolver carta fechada ao baralho.
- Criar moedas e extras.
- Usar chat/mensagens rapidas como demonstracao.

## Papel No Desenvolvimento

O treinamento tambem pode servir como ambiente de QA leve:

- validar touch/mobile;
- testar responsividade do HUD;
- reproduzir cenarios de pilhas;
- testar fisica sem depender de uma sala real.

## Condicoes Antes De Implementar

- Definir se sera offline/local ou sala temporaria.
- Criar roteiro de passos.
- Criar indicadores visuais sem poluir o modo casual.
